Watchly User Guide

Learn how to use your personal watchlist

Getting Started

Welcome to Watchly! This guide will help you manage your movies and TV shows effectively.

Adding Items

  • Click "+ Add Show" button
  • Enter the title, select status (To Watch/Watched/Upcoming)
  • Add genres separated by commas (e.g., Action, Drama, Comedy)
  • Optionally add date, release year, and notes
  • Check "Movie" if it's a movie instead of a TV show
  • Click "Add to Watchlist"

Managing Items

  • Mark Watched/Unwatched: Toggle completion status
  • Add Season/Movie: Track individual seasons or movie sequels
  • Edit: Modify title, genres, notes, or other details
  • Delete: Remove items with confirmation dialog

Search & Filter

  • Search: Type in the search box to find titles or genres
  • Status Filter: Show only Watched, Upcoming, or To Watch items
  • Genre Filter: Filter by specific genres

Data Management

  • Export: Download watchlist + rankings as JSON backup
  • Import: Upload previously exported JSON file
  • Reset All: Clear entire watchlist
  • Auto Backup: Daily cloud backup (setup required)

Status Icons

  • ✓ - Watched
  • → - Upcoming
  • ○ - To Watch

Organization

Items are automatically organized alphabetically by first letter. Your stats show total items, watched count, and upcoming releases.

Leaderboard

  • Personal Rankings: Create your own ranked list of favorites
  • Add Items: Select from dropdown to add watchlist items to leaderboard
  • Drag & Drop: Reorder items by dragging them up/down
  • Remove Items: Click × button with confirmation dialog

Trakt.tv Integration

Automatically sync your watch history from Netflix, Prime Video, Disney+, and other streaming services using Trakt.tv.

What is Trakt.tv?

  • Free service that tracks what you watch across streaming platforms
  • Browser extension auto-detects when you watch shows/movies
  • Sync your watch history to Watchly with one click

Step 1: Create Trakt Account

  • Go to trakt.tv
  • Sign up for a free account
  • No credit card required

Step 2: Install Trakt Browser Extension

  • Visit trakt.tv/apps
  • Install the extension for your browser (Chrome, Firefox, etc.)
  • The extension will automatically track what you watch

Step 3: Create Trakt API Application

  • Go to trakt.tv/oauth/applications/new
  • Sign in to your Trakt account
  • Name: Watchly
  • Redirect URI: Copy from Watchly settings page
  • Click "Save App"
  • Copy the Client ID and Client Secret

Step 4: Connect in Watchly

  • Go to Settings page in Watchly
  • Find "Trakt.tv Integration" section
  • Click "Connect Trakt.tv Account"
  • Paste your Client ID and Client Secret
  • Click "Save & Connect"
  • Authorize Watchly to access your Trakt account

How It Works:

  • Watch shows on Netflix, Prime Video, etc.
  • Trakt browser extension tracks automatically
  • Click "Sync Now" in Watchly to import your history
  • All watched shows/movies appear in your watchlist
  • Includes poster images, genres, and watch dates

Auto Backup Setup

Step 1: Get GitHub personal access token

  • Go to github.com/settings/tokens
  • Click "Generate new token" (Fine-grained token)
  • Give it a name (e.g., "Watchly")
  • Set expiration (recommended: No expiration)
  • Repository access: Select "Public Repositories (read-only)"
  • Scroll to Account permissions (NOT Repository permissions)
  • Find "Gists" and set to "Read and write"
  • Click "Generate token" and copy it (starts with github_pat_...)

Step 2: Setup in Watchly

  • Go to Backup page in Watchly
  • Click "Setup GitHub"
  • Paste your token
  • Click "Save"
  • Click "Test Connection" to verify
  • Click "Force Backup Now" to create your first backup

How it works:

  • Backs up automatically every 1 minute when changes are made
  • Creates one private GitHub Gist (updates same file)
  • Access your backup at gist.github.com
  • Includes both watchlist and leaderboard data
  • Click "View Backup" button to see your data

Sync Across Devices

Setup on First Device:

  • Complete Auto Backup setup (see above)
  • Click "Force Backup Now" to create your backup
  • Click "View Backup" to open your GitHub Gist
  • Copy the Gist ID from the URL: gist.github.com/username/GIST_ID

Setup on Additional Devices:

  • Open Watchly on your new device
  • Go to Backup page
  • Click "Setup GitHub"
  • Enter your GitHub token (same one from first device)
  • Enter the Gist ID you copied
  • Click "Save"
  • Click "Sync from Gist" to download your watchlist
  • Refresh the page to see all your data

Daily Usage:

  • Make changes on any device: Auto-backup runs every minute
  • Switch devices: Click "Sync from Gist" to get latest data
  • Force Backup Now: Manually push changes immediately
  • Sync from Gist: Pull latest changes from GitHub — replaces local data with backup

Important: Sync is a full replace — the backup becomes your local data. Always Force Backup on one device before Syncing on another to avoid losing recent changes.

Accessing Your Backups

  • View Backup: Click "View Backup" button on Backup page
  • Direct Access: Go to gist.github.com (sign in to see private gists)
  • Download: Click "Raw" button in gist to download JSON file
  • Restore: Use Import function in Watchly with downloaded file
  • Instant Updates: Every change automatically saves to same gist

Data Storage

  • Local Storage: Data saved in browser (can be lost)
  • Auto Backup: Cloud backup to GitHub Gists (recommended)
  • Manual Export: Download JSON files for safekeeping
  • Import: Restore from JSON files anytime
  • Combined Backup: Export includes both watchlist and rankings

Security

Use the "Lock" button to log out and secure your watchlist. You'll need to re-enter the password to access it again.
